## Levers if costs surprise you

1. **Cache hot reads.** If the agent repeatedly fetches the same record in a
   session, cache it. See
   [Architecture → Design decisions](/docs/architecture#design-decisions) for the
   pattern.
2. **Tighten topic scope.** A narrower classification description means fewer
   off-topic turns the LLM has to reject.
3. **Lower data refresh cadence.** Real-time ingestion is expensive; many CIs
   are happy with hourly or daily refreshes.
4. **Batch external callouts.** Replace per-record callouts with bulk calls
   wrapped in a queueable.
5. **Archive cold records.** Storage cost compounds; archive records past the
   retention window per policy.

## Forecasting checklist

- [ ] Volumes confirmed with the customer (don't guess)
- [ ] Pricing assumptions dated and sourced (link to the order form / pricing sheet)
- [ ] One-time vs. recurring costs separated
- [ ] License changes flagged (e.g. new Agentforce SKUs)
- [ ] Forecast horizon agreed (12 months is typical)
- [ ] Sensitivity analysis: what does +50% volume do to monthly cost?
