## Salesforce platform

| Term | Meaning |
|------|---------|
| **Apex** | Salesforce's server-side, Java-like language. |
| **CDC** | Change Data Capture — push notifications for record changes. |
| **DLO / DMO** | Data Lake Object / Data Model Object — Data Cloud's raw and harmonized layers. |
| **DX / SFDX** | Salesforce Developer Experience — the modern source-driven dev workflow + CLI. |
| **FLS** | Field-Level Security — controls which users can see/edit individual fields. |
| **Flow** | Salesforce's declarative automation tool (record-triggered, screen, scheduled, etc.). |
| **LWC** | Lightning Web Component — the modern Salesforce UI framework. |
| **Named Credential** | Salesforce's stored auth + endpoint config for outbound callouts. |
| **OWD** | Org-Wide Defaults — the base sharing posture before sharing rules apply. |
| **Permset / PSG** | Permission Set / Permission Set Group — additive access bundles. |
| **SOQL / SOSL** | Salesforce Object Query Language / Search Language — read APIs for data. |
| **`sf` CLI** | Salesforce CLI v2 — the command-line tool used for deploys, tests, data, and Agentforce. |
