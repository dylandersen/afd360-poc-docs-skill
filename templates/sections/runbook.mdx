## Incident classification

| Severity | Definition | Response time | Comms |
|----------|-----------|---------------|-------|
| **P1** | Workload completely down for all __PERSONAS__ | < 15 min | Sponsor + on-call |
| **P2** | Major feature broken; workaround exists | < 1 hour | On-call + customer admin |
| **P3** | Minor feature; affects < 10% of users | next business day | Backlog |
| **P4** | Cosmetic or low-volume edge case | best effort | Backlog |

## Common procedures

### Re-deploy from clean state

<Steps>
  <Step>
    Confirm you're targeting the right org: `sf org display --target-org __CUSTOMER_SLUG__-poc`
  </Step>
  <Step>
    Pull latest: `git pull origin main`
  </Step>
  <Step>
    Validate-only deploy first:
    ```bash
    sf project deploy validate --target-org __CUSTOMER_SLUG__-poc --test-level RunLocalTests
    ```
  </Step>
  <Step>
    Deploy:
    ```bash
    sf project deploy start --target-org __CUSTOMER_SLUG__-poc
    ```
  </Step>
  <Step>
    Re-run the smoke test from [Setup → Verify](/docs/setup#verify).
  </Step>
</Steps>

### Reset sample data

<Steps>
  <Step>
    Back up first if there's any non-synthetic data: `sf data export tree --query "..."`
  </Step>
  <Step>
    Wipe + reload:
    ```bash
    sf data delete bulk --sobject Case --target-org __CUSTOMER_SLUG__-poc --where "..."
    sf data tree import --plan data/plan.json --target-org __CUSTOMER_SLUG__-poc
    ```
  </Step>
</Steps>

### Re-authenticate Named Credentials

<Steps>
  <Step>
    Setup → Named Credentials → click the failing credential → **Edit**
  </Step>
  <Step>
    Re-enter or re-authenticate. If using OAuth, click **Authenticate** to refresh.
  </Step>
  <Step>
    Verify with a small test callout (anonymous Apex or a manual flow run).
  </Step>
</Steps>

### Rotate a credential

<Steps>
  <Step>
    Generate the new credential in the source system (whatever owns __INTEGRATIONS__).
  </Step>
  <Step>
    Update the Named Credential **before** revoking the old one.
  </Step>
  <Step>
    Verify the new credential works (small callout).
  </Step>
  <Step>
    Revoke the old credential at the source.
  </Step>
  <Step>
    Note the rotation in [Release Notes](/docs/release-notes) under **Security**.
  </Step>
</Steps>
