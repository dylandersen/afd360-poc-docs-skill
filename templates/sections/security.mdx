<Callout type="error" title="Never commit secrets">
No `.env`, no `apex:executeAnonymous` with hardcoded keys, no credentials in MDX.
If a credential leaks into git history, rotate immediately and rewrite history with
`git filter-repo` or BFG.
</Callout>
